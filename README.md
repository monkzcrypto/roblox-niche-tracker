# Roblox Niche Tracker

Finds which Roblox game niches and names are doing well (games with 5,000+ CCU)
and scores which niche is best to build a game in.

- Runs by itself on GitHub every 3 hours (Actions tab). A full scan for new games happens once a day.
- The report is published with GitHub Pages (Settings > Pages shows the link).
- Saved data lives on the `data` branch; the report lives on the `gh-pages` branch.

To run it right now: Actions tab > "Update niche tracker" > Run workflow.
